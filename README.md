# 🚨 SIGANA JATIM  
**Sistem Informasi Siaga Bencana Jawa Timur**

SIGANA JATIM adalah aplikasi manajemen bencana berbasis mobile yang dirancang untuk mendukung **pelaporan, pemantauan, dan koordinasi secara real-time** di lingkungan BPBD Provinsi Jawa Timur.  
Aplikasi ini menghubungkan personel lapangan dan pusat kendali (PUSDALOPS) dalam satu ekosistem digital terintegrasi.

---

## ✨ Fitur Utama

- 🔐 **Autentikasi Berbasis Role (RBAC)**  
  Mendukung multi-peran: *Agen (Lapangan)*, *Admin (PUSDALOPS)*, dan *Tamu*.

- 📊 **Dashboard Real-time**  
  Menampilkan informasi situasional seperti data bencana, cuaca, dan aktivitas seismik.

- 🗂️ **Riwayat & Arsip Laporan**  
  Penyimpanan laporan bencana secara terstruktur dengan visualisasi berbasis peta.

- ⚡ **Pelaporan Cepat (Quick Report)**  
  Formulir digital terstandarisasi dengan **geotagging otomatis (GPS)** untuk akurasi lokasi.

- 🛠️ **Manajemen Laporan (Admin)**  
  Notifikasi real-time, verifikasi laporan, dan pelacakan status (*Menunggu, Diproses, Selesai*).

- 🔔 **Push Notification (FCM)**  
  Pengiriman notifikasi instan menggunakan Firebase Cloud Messaging.

- 📞 **Hotline & Portal Informasi**  
  Akses berita resmi serta kontak darurat berbasis lokasi pengguna.

---

## 🎯 Tujuan

Meningkatkan **kecepatan respon**, **akurasi data**, dan **efisiensi koordinasi**  
dalam penanggulangan bencana melalui transformasi digital.

---

## 🧱 Tech Stack

- Android (Kotlin)
- Firebase (Firestore, FCM)
- Google Play Services (Fused Location Provider)
- Cloud Functions

---

## 📌 Catatan

Proyek ini dikembangkan sebagai bagian dari digitalisasi sistem penanggulangan bencana  
di lingkungan BPBD Provinsi Jawa Timur.
